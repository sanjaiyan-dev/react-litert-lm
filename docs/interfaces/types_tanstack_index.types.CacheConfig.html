    gcTime?: number

    Time in milliseconds until unused data is removed from the cache.

    Remarks

    This is the "garbage collection" time. Data that hasn't been accessed since this duration will be permanently removed from memory. Must be >= staleTime for predictable behavior.

    Default

    Infinity

    OptionalstaleTime

    staleTime?: number

    Time in milliseconds until the data is considered stale.

    Remarks

    During the stale time window, cached data is used immediately without background refetch. After stale time expires, the next query will trigger a background refetch while still using the stale data initially (if available).

    Default

    720000 (12 minutes)
